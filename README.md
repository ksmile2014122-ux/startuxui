# DITTO 투자 기록 프론트엔드

Figma 화면을 참고해 만든 모바일 중심 시연 프로젝트입니다. 외부 패키지 설치 없이 Node.js로 실행합니다.

## 실행

VS Code에서 이 폴더를 열고 새 터미널에서 다음 명령을 실행하세요.

```sh
npm run dev
```

브라우저에서 http://localhost:5173 을 여세요. 종료는 터미널에서 Ctrl+C입니다.
Node.js는 https://nodejs.org 에서 LTS 버전을 설치할 수 있습니다.

## 기능

예시 계정 시작과 닉네임 설정, 추천/팔로잉 피드, 종목 검색, 일지 작성과 필수 입력 검사, 임시저장, 공개범위 선택, 미리보기, 로컬 게시, My Ditto, 콘텐츠 저장, 댓글 시연, 신고 양식, 라이브/쇼츠 시연 화면을 제공합니다.

작성한 일지와 닉네임, 팔로우 및 저장 상태는 브라우저 localStorage에 저장합니다. 공개범위는 시연용 표시이며 서버 권한 제어가 아닙니다. 브라우저 데이터를 지우면 기록도 사라집니다. 댓글은 화면을 이동하면 초기화됩니다.

실제 로그인, 계좌 연동, 자산 인증, 시세 API, 영상 스트리밍, 다른 이용자와의 공유는 연결되지 않았습니다. 이미지 원본 에셋을 별도로 받지 않아 인물 사진과 영상 이미지는 재사용하지 않았으며, 차트는 시연용 SVG입니다. 모든 첨부 화면을 픽셀 단위로 재현한 버전은 아닙니다.

## 구조

- index.html: 시작 문서
- src/app.js: 화면과 상호작용
- src/style.css: 반응형 스타일
- server.mjs: 로컬 개발 서버

```sh
npm run check
```

## 디자인 재구현 버전

첨부한 780×1688 디자인의 390×844 논리 크기를 기준으로 화면과 보조 상태를 재구성했습니다. 기본 HTML/CSS/JS로 실행되며 외부 패키지 설치가 필요하지 않습니다. 실제 UI는 DOM으로 구현하며 인물/영상/차트의 일부 이미지 영역은 제공받은 화면 이미지를 CSS 배경으로 표시합니다. 첨부 이미지 원본 전체도 assets에 포함되어 있으므로 원본 사진 에셋을 받으면 교체할 수 있습니다. 라이브와 쇼츠는 정지 이미지 시연이며 실제 재생 기능은 없습니다.

주요 주소: /#start, /#home, /#write, /#preview, /#my, /#profile, /#badges, /#live, /#live-room, /#shorts.

Vercel: Root Directory 기본값(빈 값), Framework Other. vercel.json이 빌드 없이 최상위 파일을 배포하도록 설정합니다. GitHub push가 자동 배포를 실행하도록 연결되어 있다면 업로드 후 자동 배포될 수 있습니다.

검증: JavaScript 구문 검사. 이 환경에서 미리보기 브라우저가 localhost에 연결되지 않아 시각 비교는 완료되지 않았습니다. 픽셀 단위 일치가 검증된 버전은 아닙니다.
